# 经验总结：碧蓝航线动态壁纸工具开发实录

> 本文档是 `AGENTS.md` 的详细版。每一条都来自真实发生的 bug/踩坑，含具体修法与验证方式。
> 适用场景：本仓库后续开发；以及任何"游戏立绘提取 + Spine/Live2D 预览 + Wallpaper Engine 导出"类项目。

---

## 1. 架构骨架（可整体复用到新项目）

- **插件注册表**（`plugins/sources|extractors|exporters` + `core/registry.py`）：换游戏 = 加插件，不动主流程。
- **无框架 Python HTTP 后端**（`backend_server.py`，`BaseHTTPRequestHandler`）+ 统一 bridge 层（前端所有调用走 `call()`，支持 pywebview 原生桥 / mock / HTTP 三路切换）。
- **`run_tool` 进程内加载 tools 脚本**（`importlib.util` 按路径加载 + 全局 `sys.argv` 切换 + 一把跨模块共享锁 `named_lock("azurlane_sysargv")`）：打包版无法用 `sys.executable` 起子进程（frozen 下是 exe），必须进程内跑，且多个工具共享 sys.argv/cwd 必须串行化。
- **pywebview 桌面壳**：窗口尺寸/最大化持久化到 `%APPDATA%\<app>\prefs.json`，localStorage 固定 storage_path；F5/Ctrl+R 刷新绑定。
- **端口隔离**：dev 后端 8766 / Vite 5173；打包版后端 8770 / 静态 5174。前端 API 地址只走 `VITE_API_BASE`（`.env.development` / `.env.packaged`），打包脚本强制 `--mode packaged` 并校验产物无 dev 端口（否则打包版连上开发后端，表现诡异难查）。

## 2. Spine 渲染避坑（最高频的坑）

- **预乘 alpha**：碧蓝 Spine 贴图全部是预乘 alpha（半透明像素 RGB ≤ alpha）。上传前必须
  `gl.pixelStorei(gl.UNPACK_PREMULTIPLY_ALPHA_WEBGL, false)`。设 true 会被浏览器再乘一次，
  `drawSkeleton(skeleton, true)` 按预乘混合渲染 → 半透明区域变成 C·A²，明显变暗
  （灰线/黑块/纱裙发暗/Additive 光效错误）。不透明像素不受影响，所以只有半透明细节多的皮肤才暴露。
- **独立背景 PNG（*BG.png）是直通 alpha**：alpha=0 的像素 RGB 仍有残留色（实测俾斯麦Zwei 均值 140+）。
  必须 `SRC_ALPHA, ONE_MINUS_SRC_ALPHA` 混合（残留 RGB × alpha(0) = 0，透明区透出下层）；
  误用 `ONE`（预乘混合）会把残留 RGB 当不透明 → 花屏/破碎。**同 gl 上下文两种贴图并存时逐层设混合**。
- **多骨架分层（_T 人物 / _B 背景 / _M 舰装）**：
  - **渲染顺序**：背景永远先画。`build_local_index.py` 的排序只认 `_bg.skel` 导致 `duyisibao_2.skel`
    （人物）排在 `duyisibao_2B.skel`（背景）前 → 背景盖住人物。修复：`isBgLayer`（skel 名去后缀后以
    `B/BG/_B/bg/_bg` 结尾，可带数字）+ `renderOrder()` 背景优先。三处同步：预览组件、导出模板、索引构建。
  - **bestSkin**：遍历 `data.skins` 实例化 Skeleton 数可见附件，选最多的。足尖弓矢 default skin 只有脚，
    skin "1"/"2" 才是全身。注意：透明插槽（slot.color.a<0.01）与 `kkkkk` 位置标记不计入。
- **运行时版本**：spine-webgl-3.8.js 配 3.8 二进制 .skel；换游戏先确认 Spine 版本（4.x 需换运行时/转换工具）。

## 3. 取景算法（computeBounds，本次调试最多的部分）

**完整取景链（预览与导出模板两处一致）**：

```
1. 背景层取景：有背景层（B 后缀）且背景为横构图（宽≥高）、面积在主体层 [0.15, 8] 倍之间
   → 以背景层包围盒 + 8% 内边距为取景框（背景定义整幅场景，人物渲染其中）
2. contentFrame：64×64 网格密度加权取景（按附件面积加权），只有内容明显小于原始包围盒时才裁剪
3. denseAreaFrame：保留面积 ≤ 最大附件 40% 的部件 + 再网格密度裁剪（滤掉散落的云/浪花/骷髅）
4. 逐层兜底：取最小层面积 ×4 倍内的层合并（背景/特效层不参与取景）
```

**人物适配（applyCharacterFit）**：人物（非背景层）高度 > 背景 1.15 倍时，等比缩到背景高度的 70%，
中心锚定。**锚点公式**：spine Skeleton 变换是 `world = local*scale + (skeleton.x, skeleton.y)`
（源码 `Bone.updateWorldTransformWith`），以中心 (cx, cy) 为锚点需 `skeleton.x = cx*(1-s)`。

**真实案例**（每个都是"几何包围盒 ≠ 视觉比例"）：
- 战士的小憩（DEAD MASTER）：云朵把宽撑到 1.2 万 → denseAreaFrame 面积过滤收窄 72%。
- 月下起舞（新泽西）：人物骨架是背景 2.08 倍（像素实测 alpha>96 仍是 2 倍）→ 背景取景 + 人物缩到 55%→70%，
  对照官方海报（人物占画面 50-60%、背景铺满、月亮 1/3）验证。
- 两人的秘密特训：`duyisibao_2.skel` 排在 `duyisibao_2B.skel` 前 → 背景盖住人物（z-order bug）；
  人物 1.49 倍背景 → 也需缩放。**教训：人物/背景比例靠像素实测（渲染后扫 alpha 包围盒），不要信几何包围盒**。
- 华甲_2：竖构图小背景（1141×1842）是装饰背板 → 横构图护栏排除，回退常规取景。

## 4. Live2D（pixi-live2d-display 0.4.0）

- **Meta.Loop 被忽略**：库解析了 `.motion3.json` 的 Loop 但从未应用 `setIsLoop` → 动作播完自动
  `startRandomMotion("Idle")` 随机切姿势。修复：监听 **motionManager**（不是 model）的 `motionStart`
  强制 `setIsLoop(loop)` + `groups.idle = '__none__'`。
- **同优先级动作被拒**：动作强制循环后 currentPriority 不复位，`MotionState.reserve` 拒绝同优先级新动作。
  切换动作前必须先 `stopAllMotions()`。
- **命中区**：官方 model3.json 不声明 HitAreas，但 moc3 内置 TouchHead/TouchBody/TouchSpecial/TouchDragN/TouchIdleN，
  动态探测注入 `internalModel.settings.hitAreas` 即可（共享模块 `wallpaper-layout.js` 的 `setupL2DHitAreas`）。
- **透明 WebGL 画布拖拽虚影**：`preserveDrawingBuffer: true`。

## 5. 预览 = 导出（一致性纪律，血泪教训）

- **布局算法单一事实来源**：`templates/wallpaper-layout.js`（`spineCamera`/`l2dLayout`/`anchor`/`clampScale`/`clampOffset`），
  预览组件 import、导出模板 `<script src>` 引用同一份。相对值语义（scale % / offset % / 锚点 0-1）任意分辨率一致。
- **取景/渲染逻辑是各自拷贝**：`computeBounds`/`denseAreaFrame`/`renderOrder`/`applyCharacterFit` 在
  `SpinePreview.vue` 与 `wallpaper_spine.html` **各有一份**。历史事故：预览加了 denseAreaFrame 忘了同步模板
  → 导出后"背景被云撑爆的皮肤"人物偏小。**改一处必须 grep 函数名核对另一处**。
- **源码 ↔ 构建产物**：L2D 导出用 `templates/live2d-app.js`（vite build 产物），源码是 `live2d_app_src.js`。
  历史事故：给 src 加了 `VOICE_FALLBACK` 没重建 → 打包版语音兜底失效。改 src 必重建。
- **取景逻辑在导出端要能"独立算出"**：导出壁纸没有 Vue 组件，取景/适配代码必须完整内嵌模板，
  不能假设有共享运行时。

## 6. Wallpaper Engine 导出

- **project.json 原生字段**：slider 必须带 `value/min/max` + `editable/fraction/index/order`
  （WE 编辑器自己保存的格式，避免导入时误解析滑块为最大值）。
- **首次属性推送守卫（陷阱 4）**：WE 加载时推一次"全部属性"（含 config.json 按壁纸路径存的历史覆盖值），
  且**不一定包含 alignment**。守卫必须无条件跳过第一次（`_initialPropsApplied`），以导出内联
  `SCALE/OFFSET/ALIGNMENT`（或 `__L2D_INIT`）为准；之后单属性变更仍生效。
- **用户偏好开关**（语音/开场动画/互动，bool 属性）：与布局不同，**在首推里单独采纳**（重启后保持），
  之后实时切换。L2D 运行时里 `interaction` 控制器必须提升为模块级（否则属性监听器够不到）。
- **一键应用 vs 手动拖入**：`apply_wallpaper` 复制到 `projects/myprojects/`（ASCII 目录名，中文名会被
  openWallpaper 写乱码进 config，重启丢壁纸）再 `-control openWallpaper`；手动拖入 WE 编辑器有滑块写最大值风险。
- **导出目录随机后缀**：`project_dir_name` 每次导出加 8 位随机后缀——WE 按目录路径记忆覆盖值，新目录=全新壁纸。

## 7. 语音管线

- cue 包（官方 CriWare ACB）下载 → vgmstream 逐条解码 wav（`tools/vgmstream/` 本机工具，不入库）。
- **两个子进程坑**：`CREATE_NO_WINDOW`（控制台 exe 每个 cue 闪黑框）；`encoding='utf-8', errors='replace'`
  （系统默认 GBK 遇到日文 cue 名 → `UnicodeDecodeError` 崩请求线程，实测导致后端整进程退出）。
- **回退链**：cue 回退（touch_head → touch_1 → touch_2）与台词回退（headtouch → touch → touch2），
  保证点击必有语音/有字。词表按船借用（`words_for`）。
- **语音是 L2D 专属**：Spine/静态不下载语音（避免额外耗时）；清理接口保留"有已下载 L2D 皮肤"的船。

## 8. 打包与发布（PyInstaller onedir）

- `requirements.txt` 与 `azurlane.spec` 的 `collect_all` 必须一致（本次补了 pypinyin/fmod_toolkit/pyfmodex/archspec/humanfriendly，缺一个新机打包即崩）。
- **hiddenimports 集中登记运行时动态 import**：`core.voice` 是模块级 body 内延迟 import，静态分析漏抓
  → 打包版 `ImportError`。spec 登记 + `build_pack.py` 自检可 import。
- **提取器必须随包**：`references/UnityPyLive2DExtractor` + `azur-paint`（进程内 runpy 运行，禁止子进程）。
- **验收验产物**：`verify_package.py --clean` 真实下载 static/live2d/spine 三类皮肤，检查
  合成 painting.png 尺寸（≥1000px）、model3.json+moc3+动作数（≥10）、skel+atlas 存在，再三种导出 + 并发一致性。
- **打包版从空状态开始**：排除 `local_skins.json`，启动时空索引初始化（否则前端 fetch 404 显示"共 0 艘"）。
- 打包目录必须可写（勿放 Program Files）；`pyfmodex`/fmod.dll 收集警告可忽略（走 vgmstream 不碰 fmod）。

## 9. 前端工程陷阱

- **keep-alive 资源泄漏**：通用 `<keep-alive>` 缓存所有路由 → 隐藏页 WebGL/rAF 常驻。修：`:include` 只缓存
  GalleryView + 预览组件 `onDeactivated` 暂停（Spine 停 rAF、L2D 停 ticker、停语音），`onActivated` 恢复。
- **async load() 竞态**：`await` 恢复后组件可能已卸载 → 每个 await 后查 `disposed`，卸载时置位。
- **事件绑定幂等**：`syncMode()` 被调用两次（onMounted + load 末尾）→ 不先解再绑会绑两遍、卸载只解一遍，
  残留引用已销毁实例的僵尸监听。
- **Vite EBUSY 崩溃**：编辑器原子写产生 `*.tmpdir` 临时目录，chokidar 在 Windows watch 到即 EBUSY
  崩整个 dev server（本会话崩了 3 次）→ `server.watch.ignored: ['**/*.tmpdir/**', '**/.vite/**']`。
- **HMR 不重挂载**：keep-alive 缓存页里的组件，HMR 只换组件定义、不重跑 onMounted → "改了不生效"。
  排查先确认 Vite 伺服内容（`fetch /src/xxx.vue` grep 标记），再让用户 F5/切皮肤。
- **bridge.callBackend 检查 resp.ok**：否则错误页/空 body 被误报成"后端服务未启动"。
- **Naive 主题变量只收纯色**：`themeOverrides` 里放 `linear-gradient` 会 `[seemly/rgba]: Invalid color`；
  渐变用 CSS 覆盖层（themes/*.css）。JS 管语义色、CSS 管视觉覆盖，两处要保持同步。
- **按钮 hover 回落到水彩蓝**：主题 CSS 的 hover 规则只写 box-shadow 没写 background，优先级低于全局
  `.wc-btn.gradient:hover` 的水彩蓝 → hover 变蓝。补主题色背景（比常态略亮 + 光晕）。

## 10. 验证方法论（怎么证明改对了）

1. **headless Edge 截图**：`msedge.exe --headless --disable-gpu --screenshot=... --virtual-time-budget=N --hide-scrollbars URL`。
   注意 `--virtual-time-budget` 不等网络请求，内嵌数据/同步加载更可靠；`--dump-dom` 可抓 `<pre>` 输出。
2. **PIL 像素分析**：`readPixels` 扫 alpha 包围盒（区分 alpha>8 含头发特效 / alpha>96 实体），算尺寸比例。
   **人物/背景真实比例必须像素实测，几何包围盒会被头发/特效撑爆**。
3. **视觉模型（vision skill）**：描述构图（人物占画面 %、背景可见度、是否裁切、位置关系），
   多个候选方案分别渲染对比。
4. **对照官方海报定"正确构图"**：下载官方立绘/海报（wiki.biligame 等），视觉量化
   （人物占画面 50-60%？月亮 1/3？人物 1.5 倍沙发？），再反推缩放系数。**不要凭感觉调参**。
5. **产物级验证**：改 JS 先 `node --check`（模板提取内联 script、占位符替换后校验）；
   改后端重启进程；改打包跑 `build_pack.py` 自检 + `verify_package.py --clean`。

## 附：常见现象 → 根因速查

| 现象 | 根因 | 修法 |
|---|---|---|
| 半透明纱裙/光效变暗 | 预乘贴图被二次相乘 | `UNPACK_PREMULTIPLY_ALPHA_WEBGL=false` |
| 背景花屏/破碎 | 直通 alpha 背景误用 ONE 混合 | 背景图用 `SRC_ALPHA` 混合 |
| 人物在背景后面 | layers 顺序 B 排后 | `isBgLayer` + `renderOrder` 背景先画 |
| 导出后人物偏小/取景不一致 | 预览与导出模板取景逻辑不同步 | grep 函数名核对两处 |
| L2D 随机换姿势 | Meta.Loop 被忽略 | motionManager `setIsLoop` + `groups.idle='__none__'` |
| WE 滑块变最大值 | 编辑器导入写覆盖值 | 一键应用 + project.json 原生字段 |
| 重启 WE 丢壁纸 | 中文路径乱码 | 副本目录 ASCII 名 |
| 下载时疯狂跳黑框 | vgmstream 无 CREATE_NO_WINDOW | 加 creationflags |
| 后端莫名崩线程 | GBK 解码子进程输出 | `encoding='utf-8', errors='replace'` |
| 打包版语音 ImportError | hiddenimports 漏登记 | spec 加 `core.voice` |
| 隐藏页还在烧 GPU | keep-alive 全缓存 | `:include` + `onDeactivated` 暂停 |
| dev server 随机崩 | 编辑器 tmpdir 被 watch | `watch.ignored` tmpdir |
| hover 变蓝 | 主题 hover 缺 background | 补主题色背景 |
